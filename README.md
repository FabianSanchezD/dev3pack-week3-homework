# Dev3Pack - Week 3 Homework

## El reto: sus primeros programas en Solana

Esta semana juntás todo lo visto en las tres semanas en un programa de Solana! No tiene que ser grande: buscamos algo pequeño, que funcione de punta a punta y que entiendas por completo.

Sus programas deben tener:

- **Programa on-chain con Anchor**: al menos una instrucción que cree o modifique estado (por ejemplo, una cuenta PDA).
- **Conceptos de las semanas anteriores**: cuentas, transacciones, PDAs, y tokens si encajan con tu idea.
- - Opcional: **Frontend o cliente con Solana Kit** (`@solana/kit`): que se conecte a una wallet o firmante, llame a tu programa y muestre el estado on-chain.

## Ideas de ejemplo

Elegí una o proponé la tuya, siempre que sea simple:

- Contador o votación por wallet.
- Lista de tareas guardada en PDAs.
- Libro de visitas (guestbook) con mensajes cortos.
- Tip jar que recibe SOL o un token SPL.

## Requisitos mínimos

1. El programa Anchor compila y tiene al menos un test.
2. Funciona en una red local o en devnet.
4. Un `README.md` dentro de tu carpeta explicando qué hace la app y cómo correrla.

## Cómo entregar

Cada estudiante hace un **pull request** con su app dentro de una carpeta con su usuario de GitHub en `submissions/`. Leé los pasos en [la guía de entregas](submissions/README.md).
